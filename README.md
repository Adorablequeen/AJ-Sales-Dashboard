# 🛍️ AJ Sales Dashboard

This project presents a **comprehensive sales analytics dashboard** built to visualize and interpret key performance indicators across multiple malls for AJ Retail Stores. Designed and analyzed by **Aishat Atanda**, the dashboard gives critical insights into customer demographics, purchasing behavior, and revenue trends.

## 📊 Dashboard Overview

### 💰 Key Metrics
- **Total Revenue:** ₦251,505,790
- **Total Transactions:** 99,457
- **Average Price:** ₦689
- **Average Quantity Purchased:** 3
- **Average Customer Age:** 43

## 🔎 Insights Breakdown

### 🏬 Top Performing Malls
(Selectable on the dashboard - explore metrics per mall like Cevahir AVM, Mall of Istanbul, Zorlu Center, etc.)

---

### 🧾 Top 5 Categories by Revenue
1. **Clothing** - ₦113,996,791  
2. **Shoes** - ₦66,553,451  
3. **Technology** - ₦57,862,350  
4. **Cosmetics** - ₦6,792,863  
5. **Toys** - ₦3,980,426  

🔍 **Insight:** Clothing leads significantly, contributing nearly 45% of the total revenue.

---

### 🧑‍🤝‍🧑 Revenue by Gender
- **Female:** 59.81% (₦150,486,859)
- **Male:** 40.19% (₦101,018,931)

🔍 **Insight:** Female customers contribute a larger share to overall revenue, indicating a stronger buyer segment.

---

### 👶🧓 Revenue by Age Bracket
- **36–45:** ₦50,129,430 (Highest)
- **46–55:** ₦48,188,511
- **26–35:** ₦47,826,744
- **56–65:** ₦47,843,737
- **18–25:** ₦38,075,394
- **>65:** ₦19,164,716
- **Unknown:** ₦277,261

🔍 **Insight:** Most spending is concentrated among customers aged **26–55**, especially 36–45.

---

### 💳 Revenue by Payment Method
- **Cash:** ₦112,832,243.02
- **Credit Card:** ₦88,077,123.77
- **Debit Card:** ₦50,596,427.46

🔍 **Insight:** Cash remains the most popular method of payment.

---

### 📅 Monthly Revenue Trends
- **Peak Month:** January (₦28.89M)
- **Lowest Month:** April (₦18.72M)
- **Stable Performance:** Revenue stays fairly consistent after February.

🔍 **Insight:** Strong start in January, followed by relatively even monthly revenues. Possible seasonal spike in Q1.

## 🚀 Getting Started

This dashboard was built using Power BI with DAX modeling. For developers or analysts wanting to replicate or extend this:

1. Clone the repository
2. Use the Excel dataset (not shared publicly due to privacy)
3. Open the Power BI file
4. Customize filters for mall/year/category as needed
